📋 実行手順（3ステップ）
================================================================================

【ステップ 1】API キー取得（10～30分）
  1. GitHub Personal Access Token を作成
     → https://github.com/settings/tokens

  2. YouTube Data API キーを取得
     → https://console.cloud.google.com/

  3. Claude API キーを取得
     → https://console.anthropic.com/

  4. Supabase プロジェクトを作成
     → https://supabase.com/
     → DDL を実行: db/migrations/001_init.sql

【ステップ 2】GitHub へプッシュ（2～5分）
  git push -u origin master
  （GitHub Personal Access Token が必要）

【ステップ 3】セットアップスクリプト実行（5～15分）
  python setup_interactive.py

  以下を入力:
    - YouTube API キー
    - Claude API キー
    - Supabase URL
    - Supabase Anon キー
    - Supabase Service Role キー
    - Database URL

  自動実行:
    - .env ファイル生成
    - Python パッケージインストール
    - Node.js パッケージインストール
    - 環境検証
    - GitHub Secrets 設定
    - Vercel デプロイ準備

📊 プロジェクト概要
================================================================================

名称:        ネタDB - YouTube 漫才・コント動画検索サイト
ビジョン:    YouTubeの公式漫才・コント動画から芸人・形式・設定・賞レースで
             検索できるデータベースサイト

ターゲット:  漫才・コント好きなユーザー
用途:        ネタ動画の一元管理・検索
機能:        動画検索・ネタ分類・評価管理・自動更新

技術スタック:
  フロントエンド:  Next.js 14, TypeScript, Tailwind CSS
  バックエンド:    Python 3.12, PostgreSQL
  LLM:            Claude API (Haiku/Sonnet)
  CI/CD:          GitHub Actions
  ホスティング:    Vercel (Next.js), Supabase (DB)
